TEST HARNESS NOTE
The sandbox blocks Chromium navigation to localhost/file URLs. Runtime regression testing therefore used Chromium with the actual v0.21 HTML/CSS/JavaScript loaded into an in-memory page and browser local/session storage mocked with the same Storage API surface. This tests the application event wiring, renderers, controls, routing logic, and DOM behavior without changing production source. Social Content remains the one IndexedDB-dependent page that is statically verified rather than runtime-tested in this harness.
